# 🎬 Movie Recommendation System

## Overview

The Movie Recommendation System is a web application built using HTML, CSS, and JavaScript. It uses the TMDB API to recommend movies based on genre, language, and release era.

## Features

* Movie recommendations based on user preferences
* Filter by genre, language, and era
* View movie ratings and descriptions
* Check OTT platform availability
* Watch movie trailers
* Pagination for browsing more movies
* Responsive and user-friendly interface

## Technologies Used

* HTML
* CSS
* JavaScript
* TMDB API

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Add your TMDB API key in `config.js`.
4. Open `index.html` in a web browser.

## Project Structure

* `index.html` – Main webpage
* `style.css` – Styling
* `script.js` – Application logic
* `config.js` – API key configuration
